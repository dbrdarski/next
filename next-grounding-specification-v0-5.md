## §1 The judgment frame

**GR-01 — Class [drafted; late-res §3].** Grounding is a **behavioural judgment obligation**, never formation. Subordinate obligations it consumes are governed by their own closed rules and named where used: region-table instantiation (formation; region-table spec v0.3), tuple-family length and derived facts (behavioural; tuple spec v0.3 + 0.3.1), C§9 admissibility with its guarding minimum-length facts (formation with a subordinate behavioural obligation; late-res §3), fact-graph SCC settlement (C§13.2a).

**GR-02 — Demand and origin [drafted; C§10, C§13.2a, late-res C2].** The grounding demand is a **fixed-rule compiler obligation**, raised: (i) when a proven return fact is demanded across a recursive boundary — fact admission is **per-row grounded**, `I ⊆ GroundedRows(instance)` [C§13.2a]; (ii) at a call seat whose completion evidence is demanded (the application package's three-valued completion judgment consumes it); (iii) by a `where` assertion — a deliberate early demand, resolving only once its complete semantic key can be constructed [late-res §1.2]. Origin recorded at creation; diagnostics origin-phrased [C§13]. **The obligation binds all recursion uniformly — no act-kind exemption** [user-derived, standing: effect boundary clause 1]; a pure-shaped forced loop inside an Effect stays bound — placement is not a suppression hole [user-derived, standing: clause 2].

**GR-02a — Recursion discovery: the demand-path reading [user ruling, 2026-07-30 — operational statement over existing machinery; nothing new].** Recursion is **discovered, never declared**. Every call creates its ordinary dependency demand; demands resolve along the active resolution path (the existing fact graph; C§13.2/13.2a); a demand reaching an instance **already on the current path** closes a cycle — and a closed cycle is not an error but the point where the grounding obligation fires. Self-recursion is the one-step case; mutual recursion of any length is the same detection with more path. Every call edge is followed [GR-11's ruling — all, never one], and the path records per-edge oriented Progress evidence as it walks (GR-05); a cycle the active path itself closes is checked on the spot with its composed Progress already in hand. **Correction [R-G2 1]: active traversal alone does not guarantee every round trip is presented as an active-path closure** — a memoised resolution can reach an already-settled node without re-entering its cycles. The traversal therefore *discovers* the graph and its evidence; **universal round-trip coverage is proven over the completed global dependency graph (C§13.2a), which is authoritative** (GR-07); active-path closures are opportunistic cached summaries only.

**GR-03 — Semantic keys and layers [drafted; late-res §§2, 6].**
- Grounding proposition: **`Grounded(instance, I)`** — instance = analysis instance (shape + annotated captured-environment contract tuple; C§12.3); I = input/row domain in the instance's finite row-set lattice. **I is the domain already carried by the existing domain-indexed demand and fact machinery — no new domain notion is introduced** [C§13.2; R-G1 1, clarification].
- Return fact: **`ReturnFact(instance, I, C)`** (C§13.2a, unchanged).
- Classification (§§8–9): **`WorldDecided(instance, I)`** — the **whole-call label**, minted only by GR-26's aggregation; the per-SCC evidence beneath it is the **SCC world-decided certificate**, Layer-2 with component identity, never a persistent semantic key [R-G3 3]. **No SCC identity enters any persistent key** — whole-call composition is seat-judgment wording over existing per-alternative evidence (GR-26; R-G1 2).

All three are **seat-independent**; admission and consequence are judged at each seat (EvaluationCore discipline; C§13.4, late-res §6). **Layer discipline [late-res §2]:** drift facts, landing/grid facts, segment-length facts, stability facts, closure facts, hypothesis vectors and witnesses are **proof dependencies carried in certificates (Layer 2)** — never key parameters. Reuse: proven/refuted permanent in-namespace; fact-unproven per-compilation; certificates carry the domain I, the instance's environment tuple and — for cyclic components — the full hypothesis vector [C§16].

**GR-04 — Candidate-locality is law [user, D-4].** The abilities of §§3–6 and the refutation forms of §7 are **candidates**. Outside a candidate's applicability conditions it contributes **no conclusion**: inapplicability never manufactures a refutation or a final unproven; candidates only ever add. ## §3 The numeric grounding certificate — two independent components (item 1)

**GR-05 — The certificate [decisions §2.5; R1 blocker 6; R2 high 4].** A numeric candidate proves `Grounded(instance, I)` only with **both** components:

**(1) Well-founded descent.** Every recursive transition strictly progresses in a well-founded order on the certified carrier. *Constant drift:* per textual recursive call, the drift is the C§7 transfer shift between the call's argument expression and the parameter [late-res §9], read from the call as written — one computation per textual call, cached. *Variable drift [user, D-2]:* admitted with a **call-derived positive progress floor**. **The oriented Progress quantity [R-G2 9]:** per textual call, define **`Progress = currentMeasure − nextMeasure` after the chosen orientation**; its canonical signed range — **ProgressRange** — is computed by GR-16's substitute-and-normalize followed by GR-18's forward range through the operation rules from the state's contracts. **Floor derivation [R-G1 6a] — read, never searched:** the floor is accepted **iff ProgressRange ⊑ GE(δ) with an exposed strictly positive boundary** (`GE(b)` or `GT(b)`, b > 0 → δ = b). ProgressRange is also the per-edge object GR-07 composes. `GT(0)` exposes no positive floor — Zeno stays unproven; arbitrary-rational search is not performed and not permitted. *Dense (rational) measures* require the floor δ **with a maintained ranking domain**; runs are finite by the Archimedean argument. The licensing theory is **well-foundedness of the transition relation — never a uniform runtime depth bound** [R1]: `countDown` over `GE(0) ∧ Mod(1,0)` proves with unbounded depth; C§13.3 bounds the compiler's symbolic procedure, not runtime recursion. `f = (x, s) => x >= 100 ? done : f(x + s, s / 2)` is **honestly unproven** — warning today; error under the leaning.

**(2) Landing / coverage.** Transitions must not skip the applicable base. Region and half-line bases discharge landing structurally; **point bases retain the Mod/grid alignment obligation**; finite-interval coverage and domain partitions per the C§10 core. The narrowed sentence [R1]: *integer measures with strict constant drift are intrinsic for region bases or grid-aligned point bases only.* Split witness: `f = n => n == 0 ? done : f(n − 2)` from `Equals(1)` — **grid-refuted** (1 lies off the even lattice; certificate per GR-23a). Non-vanishing progress prevents Zeno; it never proves landing.

**GR-06 — Multi-base: fixed exit only [user ruling; R1 high 7].** Progress monotone toward **one fixed exit**, or a fixed exit per domain partition, or one combined certified measure. Existential per-step switching is forbidden: the 40↔60 specimen improves toward *some* exit every step and loops forever.

**GR-07 — Mutual recursion: every round trip, checked over the completed graph [user ruling, 2026-07-30 — substance unchanged; mechanism corrected R-G2 1, 4, 7, 9].** *Discovery:* per GR-02a, the demand path discovers the graph and records, per edge, the oriented **ProgressRange** (GR-05) with its source domain; cycles the active path itself closes are checked opportunistically on the spot. *Authority [R-G2 1]:* once the ordinary global dependency graph/SCC is complete (C§13.2a), the certificate requires **every simple cycle of that completed graph** to pass — the completed graph, never the traversal order, proves universal coverage. *Graph grain [R-G2 7]:* nodes are the **existing domain-indexed analysis/fact control nodes** (instance × row/domain under the region partition); edges are **distinct reachable textual call sites**, each carrying its source domain and ProgressRange — parallel call sites remain distinct edges; "the same textual function" is not a node. *Per-cycle check [R-G2 4 + 9]:* the cycle's **composed ProgressRange is the C§7 range sum of its edge ProgressRanges**; the certificate requires **composed ProgressRange ⊑ GE(δ_cycle) with an exposed δ_cycle > 0** (integer carriers: GE(1) via strict integral progress); **a composed range straddling zero contributes no conclusion** — floors alone are insufficient when an edge's Progress can be negative. Traced [R-G2 4]: `a = (n, s) => n <= 0 ? done : b(n − 2, s); b = (n, s) => a(n + s, s)` — edge Progresses `Equals(2)` and `−s`; over `s ⊑ GE(1)` the composed range `2 − s ⊑ LE(1)` straddles zero → no conclusion; at `s ⊑ Equals(1)` it is `Equals(1)` → proven. The oscillator (one cycle; +2 then −3, composed Progress `Equals(1)`) passes; backward-trap moves (the −4 trap) remain the C§10 core's obligation. **No collapsing, forwarder-discard, or function identification is needed or used** [user, 2026-07-30]: the walk carries the current instance as part of its state and traverses intermediaries; verdicts are spelling-independent. *Advance bound [R-G2 7; corrected R-G3 1 for parallel edges]:* with N graph nodes and ≤ N·T call-site edges, **edge-labelled simple cycles in the directed multigraph** number ≤ Σ_{k=1..N} [N!/(N−k)!] · T^k — parallel call-site edges multiply per step (N = 1, T = 2: two distinct one-step cycles, and the bound gives 2, where the node-sequence bound gave 1); computable in advance from the finite counts; **stated, never computed by the implementation, never a limit** (§12).

## §4 Exact singleton fact chains — the native finiteness license (item 2)

**GR-09 — Mechanism [user-corrected lineage; decisions §2.3; recomposed per R-G1 4].** **Never evaluation.** Per **represented-exact state**: the region table's **exact unique row selection** [R4] picks the row — an exact input does not decide an opaque predicate; within the selected row, exact selection resolves every nested conditional; the resulting **selected evaluation path** yields the ordered set of **required strict recursive dependencies** — every recursive call the path evaluates, each argument transferred on exacts (C§7) to a represented-exact successor state, each an ordinary **domain-indexed fact demand on its singleton domain** [C§13.2]. Any non-exact selection, or a dependency argument failing to transfer represented-exact, ends this candidate's contribution at that state [GR-04].

**GR-10 — The license: four conditions, each read by existing machinery.**
1. **Element provenance.** Every element of every successor state comes from already-interned **pooled leaf values** — the **represented-exact initial argument alternatives'** leaves ∪ the leaves operations actually insert from body constants [R4 wording; R-G1 6e] — read off the transfer rules' part/recombination descriptions. `f = x => f([x])` fails natively: the new container's element is the prior *state*, not a pooled atom; nesting stays out **by provenance, not by any size metric**.
2. **Total-length drift ≤ 0 per required recursive dependency** [R-G1 4 rewording]. The ordinary tier-2 drift reading applied to each dependency's argument length against the state's; per-dependency constants from the text (`rest(l)` −1; `l ++ [c]` +1; a repeated whole argument 0). `g = l => g(l ++ [0])` fails (+1); drop-a-letter-add-"A" passes (0).
3. **Complete varying call state [R5].** Every recursively *varying* argument is a flat sequence under (1)–(2); every other argument **proven constant** across the recursive edges (transfer-readable); the recursive control location ranges over the finite program-derived graph — the finite factor **Q**. `f = (xs, n) => f(xs, n + 1)` is out. Completeness is a **license condition**: a loose reading's walk would neither end nor repeat, breaking C§13.3 itself. The finite-product extension (non-sequence varying components over proven-finite exact domains) is **recorded, deferred — not v1** [user].
4. **Semantic-state stability [R6].** Every semantic dependency capable of affecting selection, transfer, or base reachability — pending Mutator write-sets (read-your-writes; B5), box contents, world results, seat facts — must be **fixed across the chain** or included in the certified finite state. **v1 scope: pure / snapshot-stable recursion only.** Counterexample carried [R6]: `@mutable n = 0; @mutate f = xs => { n := n + 1; n == 10 ? done : f(xs) }` — a stability-blind walk would mint a **false closed-orbit refutation of a terminating program**, the worst verdict class; the condition prevents it; the positive proof is outside v1 chain scope (§15 #17).
